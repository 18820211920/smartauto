# SmartAuto - 非标自动化设备公司全流程管理系统（含AI能力）

## 项目概述

非标自动化设备公司ERP管理系统，覆盖销售、研发、采购、仓库、发货、验收、售后、财务、人事全链路，深度集成AI能力。

---

## 一、系统架构

### 1.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **前端** | React + TypeScript + Vite + TailwindCSS | SPA单页应用 |
| **AI对话** | React Agent 组件 + WebSocket | 流式输出，多轮对话 |
| **后端** | FastAPI + SQLAlchemy + MySQL | 高性能异步API |
| **AI服务层** | LangChain + RAG + VectorDB | 智能推理与知识检索 |
| **AI模型** | OpenAI / Claude / 本地LLM | 支持API和私有化部署 |
| **视觉AI** | 视觉大模型 | 图纸识别、质检 |
| **知识库** | Milvus / Chroma | 向量数据库 |
| **部署** | Docker + PM2 | 容器化部署 |

## 四、AI能力详细设计

### 4.1 AI智能助手

**功能定位**: 全局AI对话入口，嵌入工作台侧边栏

**核心能力**:
- 多轮对话，理解上下文
- 流式输出，实时响应
- 任务创建，自动执行
- 报表解读，数据分析
- 知识问答，RAG检索

**对话场景**:
```
用户: 帮我查看本月销售额最高的前5个客户
AI:   查询系统中本月销售数据，按金额排序，返回TOP5客户及销售额

用户: 创建一个采购申请，物料是轴承6205，数量100个
AI:   自动填充采购申请表，关联项目自动识别，价格参考历史记录

用户: 帮我分析项目A的进度风险
AI:   分析项目A的当前进度、任务完成情况、资源使用率，识别风险点
```

**技术实现**:
- 前端: React流式组件 + WebSocket
- 后端: FastAPI流式响应
- LLM: OpenAI GPT-4 / Claude Opus
- 上下文: 当前用户、租户、项目权限

### 4.2 AI图纸识别系统

**功能定位**: 研发模块核心AI能力

**核心能力**:
- 图纸上传（支持DWG/PDF/JPG/PNG）
- 图纸内容识别（尺寸、规格、材料）
- BOM自动提取
- 图纸分类归档
- 版本比对

**AI处理流程**:
```
上传图纸 → 格式转换 → AI视觉识别 → 内容解析 → BOM提取 → 人工确认 → 入库归档
```

**输出示例**:
```
图纸识别结果:
- 图纸编号: DRAW-2024-001
- 产品名称: 轴承座组件
- 关键尺寸: 直径120mm，高度80mm
- 材料要求: 45#钢
- 表面处理: 镀锌
- 提取BOM:
  1. 深沟球轴承 6205 - 2个
  2. 密封圈 - 4个
  3. 螺栓M8x20 - 8个
```

### 4.3 AI-BOM智能解析

**功能定位**: 打通图纸与采购

**核心能力**:
- 图纸→BOM自动生成
- BOM完整性检查
- 物料替代建议
- 供应商智能匹配
- 采购价格预测

### 4.4 AI视觉质检

**功能定位**: 品质管理核心AI能力

**核心能力**:
- 来料检验（IQC）自动判定
- 过程检验（PQC）异常检测
- 出货检验（OQC）全检
- 缺陷分类与计数
- 质检报告自动生成

**质检流程**:
```
拍照/上传 → AI视觉检测 → 缺陷识别 → 判定结果 → 记录存档
```

**检测项目**:
- 外观缺陷（划痕、污渍、变形）
- 尺寸偏差（AI视觉测量）
- 装配错误（零件缺失、错位）

### 4.5 AI知识库（RAG）

**功能定位**: 企业知识管理

**核心能力**:
- 文档上传与解析
- 向量索引构建
- 语义检索
- 知识图谱构建
- 答案生成

**知识来源**:
- 企业文档（制度、流程、手册）
- 合同条款
- 技术规范
- 历史案例
- 客服记录

### 4.6 AI智能客服

**功能定位**: 售后模块智能应答

**核心能力**:
- 7x24小时自动应答
- 故障诊断引导
- 备件查询推荐
- 工单自动创建
- 满意度分析

### 4.7 AI数据分析

**功能定位**: 决策支持

**核心能力**:
- 销售预测（需求预测模型）
- 库存优化（ABC分类 + 安全库存）
- 成本分析（项目成本归集）
- 异常预警（规则引擎 + AI识别）
- 智能推荐（供应商、物料、工序）

CREATE TABLE ai_model_config (

CREATE TABLE ai_conversation (

    messages JSON,                 -- 对话历史
    context JSON,                  -- 上下文数据
    model_id BIGINT,
    token_usage INT,
    create_time DATETIME,

-- AI知识库文档表
CREATE TABLE ai_knowledge_doc (

    INDEX idx_tenant_type (tenant_id, doc_type)

-- AI图纸识别记录表
CREATE TABLE ai_drawing_recognition (

    tenant_id BIGINT NOT NULL,

    recognized_content JSON,       -- AI识别结果
    bom_items JSON,                -- 提取的BOM
    confidence_score DECIMAL(5,4),-- 置信度
    status TINYINT DEFAULT 0,       -- 0待确认 1已确认 2已修正
    confirmed_by BIGINT,
    confirmed_time DATETIME,
    create_time DATETIME,
    is_deleted TINYINT DEFAULT 0,
    INDEX idx_drawing (drawing_id),
    INDEX idx_project (project_id)
);

-- AI质检记录表
CREATE TABLE ai_quality_check (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    tenant_id BIGINT NOT NULL,

    image_urls JSON,               -- 检测图片
    detected_defects JSON,         -- 检测到的缺陷
    defect_locations JSON,         -- 缺陷位置
    ai_judgment VARCHAR(20),       -- AI判定结果
    final_judgment VARCHAR(20),    -- 最终判定（人工确认）
    confidence DECIMAL(5,4),
    model_version VARCHAR(50),
    create_time DATETIME,
    INDEX idx_order (order_id)
);

-- AI日志表
CREATE TABLE ai_usage_log (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    tenant_id BIGINT NOT NULL,
    user_id BIGINT,
    module VARCHAR(50),            -- 对话/质检/识别/分析
    model VARCHAR(100),
    input_tokens INT,
    output_tokens INT,
    cost DECIMAL(10,4),
    latency_ms INT,
    status TINYINT,
    error_msg TEXT,
    create_time DATETIME,
    INDEX idx_user_time (user_id, create_time),
    INDEX idx_module (module)
);
```

## 七、API设计（AI相关）

### 7.1 AI对话接口
```
POST /api/ai/chat
  - 输入: { message, session_id, context }
  - 输出: 流式SSE响应
  - 权限: 登录用户

POST /api/ai/conversation/new
  - 创建新会话
DELETE /api/ai/conversation/{session_id}
  - 删除会话
GET /api/ai/conversation/{session_id}/history
  - 获取历史记录
```

### 7.2 AI图纸识别接口
```
POST /api/ai/drawing/recognize
  - 上传图纸，返回识别结果
  - 输入: { file, project_id, type }

POST /api/ai/drawing/bom-extract
  - 从图纸提取BOM
  - 输入: { drawing_id }

GET /api/ai/drawing/{id}/result
  - 获取识别结果
POST /api/ai/drawing/{id}/confirm
  - 确认/修正识别结果
```

### 7.3 AI质检接口
```
POST /api/ai/quality/check
  - 提交质检图片
  - 输入: { images[], check_type, order_id }

GET /api/ai/quality/{id}/result
  - 获取检测结果
POST /api/ai/quality/{id}/confirm
  - 确认/修正检测结果
```

### 7.4 AI知识库接口
```
POST /api/ai/knowledge/doc
  - 上传文档
GET /api/ai/knowledge/search
  - 语义检索
  - 输入: { query, top_k }

POST /api/ai/knowledge/rebuild-index
  - 重建向量索引
```

### 7.5 AI分析接口
```
GET /api/ai/analysis/sales-forecast
  - 销售预测

  - 库存预警
GET /api/ai/analysis/customer-churn
  - 客户流失预警

  - 报表解读
